# Offerwise Master Documentation v2.1

These five documents are intended to be used together as the implementation source of truth.

Priority when documents overlap:
1. System Design — technical architecture and data/security contracts
2. PRD — product scope and behaviour
3. Product Design Foundation — UX/product principles
4. Design System — visual/component rules
5. MVP Build Spec — implementation sequencing and acceptance gates

Non-negotiable invariants:
- Missing data is not a negative fact.
- Never invent offer-letter values.
- Material flags require evidence.
- LLM explains; deterministic rules classify.
- External estimates are clearly labelled.
- No direct accept/reject instruction.
- User-owned documents remain private.
